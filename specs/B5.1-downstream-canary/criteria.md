# B5.1 acceptance criteria

**DSC-01** `docs/downstream.tsv` lists the six projects with the eight columns; every row parses, repos are `owner/name`, `tests` is `auto` or `none`, `install` holds only `--extra`/`--group` arguments; the opt-in online check confirms each recorded pin against the project's `pyproject.toml` on its branch.
**DSC-02** `scripts/downstream_imports.py` lists every EvalKit import in a checkout by module and name with a file count, classes each as `public`, `public-elsewhere`, `internal` or `private` from the public contract, never imports downstream code, skips virtual environments, reports unparsable files without stopping, prints the EvalKit-importing test files with `--tests`, emits stable JSON with `--json`, and passes its `--self-test`.
**DSC-03** `downstream.yml` builds its matrix from the registry, runs each `auto` project's EvalKit-importing tests with this checkout installed over the pin and `-m "not live"`, has no secrets or API keys and read-only permissions, does not fail fast, and uploads a per-project artifact; `scripts/downstream_canary.py` runs the same steps on local checkouts, and a recorded baseline run against all `auto` projects is stored in `docs/measurements/`.
